I wanted a version of `tree` that worked cross-platform, showed useful file
metadata, and respected Git's ignore rules. So I wrote a small Python
command-line utility for displaying directory contents as a tree, with
information like file sizes, line counts, and modification times.

You can install `treex` from [PyPI][pypi-home], and follow development
on [GitHub][github-repo] ([MIT licensed][mit-license]).

### Usage:

```console
$ treex --help
usage: treex [-h] [-a] [-m] [-q] [-s] [directory]

List directory contents as a tree with file metadata.

positional arguments:
  directory       directory to scan (default: current directory)

options:
  -h, --help      show this help message and exit
  -a, --all       show all files (including those ignored by Git)
  -m, --modified  show file modification times
  -q, --quiet     don't show file metadata
  -s, --summary   show summary only
```
